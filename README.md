# appli

le but est de faire un site internet type quizlet qui permet d'apprendre les buques et fam'ss des .onscrits.
il faut montrer une photo du .onscrit et ensuite la buque et fam'ss en réponse.

je veux aussi que tu fasses des jeux comme le match de quizzlet avec une leaderboard.

il faut utiliser github.io pour le frontend et firebase pour le backend.

il faut utiliser une da simple, pas d'ecriture inutile ou de bouton en doublons.
tu peux utiliser amtrad'sszaloeil comme logo et clunsois_complet.ttf comme police.

pas besoin de faire de gestion de triche.

pour les logins tu peux utiliser buques + fam'ss

les photos sont dans trombinoscope.svg
les buques sont dans liste_buques_226
et l'association de fam'ss se fait en enlevant les buques des anciens dans repartss_fam'ss_onscrit.

avec ca genere un tablal (nom, buques, fam'ss) dans un fichier .csv des 226 que tu pourras utiliser pour la suite

l'appli doit etre adapté pour etre utiliser sur mobile (avec des swipe) et sur pc (avec clavier)
